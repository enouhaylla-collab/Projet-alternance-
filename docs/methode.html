Partie 7

Comment le site est fait

Tout ce qui est compté ici est reproductible : les requêtes, les scripts et les données datées sont dans le dépôt GitHub.

Les canaux branchés

  • France Travail · API Offres d'emploi v2 : authentification OAuth2, 150 offres par page, 1 150 au maximum par requête.
  • La Bonne Alternance · API offres et recruteurs : offres d'alternance et entreprises susceptibles de recruter (marché caché).
  • Aucune donnée de LinkedIn, de l'APEC ni d'Indeed : pas de scraping.

Les scripts

  • scripts/config.py : métier, requêtes, variantes d'intitulé, dictionnaire de compétences.
  • scripts/collect.py : appelle les API et écrit data/AAAA-MM-JJ/*.csv + le journal data/extractions.csv.
  • scripts/analyse.py : lit toutes les extractions et produit docs/data/stats.json, affiché par ces pages.

L'automatisation

Un workflow GitHub Actions (.github/workflows/veille.yml) lance la collecte puis l'analyse chaque matin, et enregistre les nouvelles données dans le dépôt. Le site, publié avec GitHub Pages, affiche donc toujours la dernière extraction. Les clés d'API sont stockées dans les secrets du dépôt, jamais dans le code.

La règle RGPD pour les contacts

Les scripts ne collectent aucune donnée personnelle : seulement des offres et des entreprises (personnes morales). Les professionnels cités le sont par leur fonction et leur entreprise, pour la finalité de cette enquête ; leur nom n'apparaît qu'avec leur accord, et je le retire sur simple demande. Aucun contact n'est réutilisé à d'autres fins.

Les données

Les extractions datées (CSV) sont dans le dossier data/ du dépôt : une ligne par offre, une ligne par requête dans le journal, avec la date, le canal, les paramètres et les limites. Le README du dépôt détaille la méthode.
