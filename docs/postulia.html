1

Collecte

Chaque matin à 7 h, un déclencheur Apps Script interroge les API officielles : France Travail, La Bonne Alternance, Adzuna. Aucun scraping. Les offres hors marketing sont écartées et les doublons supprimés.

2

Enrichissement

Taille et secteur de l'entreprise : d'abord ce que dit l'offre, sinon le répertoire Sirene de l'Insee (API officielle, catégorie PME / ETI / grande entreprise).

3

Analyse et score

Un dictionnaire de ~55 compétences, outils et canaux (avec synonymes) repère les mots-clés de chaque offre et les compare à mon profil : 80 points pour la part de mots-clés maîtrisés, 20 si le contrat correspond.

4

CV et lettre

Un CV Google Docs (et sa version Word) par offre : mes réalisations liées à l'offre passent en premier, ses mots-clés en gras. La lettre cite une actualité récente de l'entreprise (Google Actualités), filtrée pour écarter les sujets sensibles.

5

Validation humaine

Rien ne part sans moi : je relis, coche trois cases, puis valide. L'envoi se fait par Gmail (CV et lettre en pièces jointes) ou j'ouvre le site de l'offre.

6

Vitrine

Après la routine, le script publie un fichier de données anonymisé dans ce dépôt GitHub via l'API GitHub ; cette page GitHub Pages l'affiche.
